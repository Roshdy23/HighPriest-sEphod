# The Priest's Ephod – An Interactive Biblical Journey

## About the Project

**The Priest's Ephod** is a simple interactive 3D game inspired by the twelve precious stones associated with the High Priest's breastplate in the Old Testament.

The player's journey begins with collecting all **twelve stones**. Once all the stones have been collected, a mysterious door opens, allowing the player to enter and explore the High Priest's **Ephod (أفود رئيس الكهنة)**.

Inside, players can discover the different features, details, and elements of the priestly garments described in the Old Testament.

## How to Play

1. Explore the environment and search for the twelve precious stones.
2. Collect all twelve stones scattered throughout the game.
3. Once you have collected them all, the locked door will open.
4. Enter through the door to discover the High Priest's Ephod.
5. Explore its different features and learn about its biblical significance.

## The Purpose Behind This Project

This project is a **voluntary initiative** created to serve the children of the church through an interactive and enjoyable learning experience.

It is developed for **معهد كاروز ابتدائي**, a church organization that I have the privilege of serving.

The idea behind the project is simple: instead of teaching children about the High Priest's garments through traditional explanations alone, why not let them explore them through a game?

By combining exploration, interaction, and biblical elements, the goal is to make learning more exciting, memorable, and engaging for children.

**The purpose of this project is not to learn or showcase Three.js. Its real purpose is to serve the children of the church and help them discover and appreciate the biblical heritage in a fun and interactive way.**

## Technologies Used

- **Three.js** – For building the interactive 3D environment and game experience.
- **JavaScript** – For game logic and interactions.
- **Claude AI** – Used as an AI development assistant throughout the implementation process.
